## 📖 Sobre o Projeto

O Discord Clone é uma aplicação Full Stack inspirada no Discord, desenvolvida com React.js, Node.js, PostgreSQL e Prisma ORM.

O projeto foi criado para praticar conceitos avançados de desenvolvimento web moderno, arquitetura cliente-servidor, APIs REST, modelagem de banco de dados e organização de aplicações escaláveis.

A plataforma permite o gerenciamento de usuários, servidores, canais, cargos e mensagens, simulando funcionalidades encontradas em aplicações reais de comunicação.

## 🛠️ Como Executar

### Clonar o repositório

```bash
git clone https://github.com/atanaelcardoso/discord-clone.git
```

### Entrar no projeto

```bash
cd discord-clone
```

### Instalar dependências

```bash
npm install
```


### Subir containers

```bash
docker-compose up -d
```

### Executar aplicação

```bash
npm run dev
```
---

### 🌐 URLs da Aplicação

Após iniciar os serviços:

| Serviço | URL |
|----------|----------|
| Frontend | http://localhost:5173 |
| Backend API | http://localhost:3000 |

O servidor backend será executado em:

```text
http://localhost:3000
```

A aplicação frontend estará disponível em:

```text
http://localhost:5173
```
